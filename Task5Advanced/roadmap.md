# Стратегический роадмап внедрения Data Mesh — «Будущее 2.0»

## Ключевые роли

| Роль | Ответственность | Кол-во |
|------|----------------|--------|
| Data Product Owner | Определяет Data Products в домене, отвечает за качество и SLA | 1 на домен (5) |
| Data Engineer | Реализует пайплайны, настраивает Kafka/Iceberg/Dremio | 3-5 |
| BI-аналитик | Создаёт дашборды в Superset, обучает пользователей | 2-3 |
| Platform Engineer | Развивает платформу (Terraform, K8s, мониторинг) | 2-3 |
| Data Steward | Управление качеством данных, тегирование, governance | 1-2 |

## Этап 1: Пилот (0-6 мес.)

**Бизнес-цель**: доказать ценность подхода

### Месяц 1-2: Подготовка инфраструктуры
- Развернуть Kafka + Schema Registry
- Настроить Yandex Cloud (Terraform)
- Развернуть DataHub
- Нанять / обучить Data Engineers

### Месяц 2-4: Пилотный домен — Финтех
- Определить Bounded Context
- Создать первые Data Products (счета, платежи)
- Настроить CDC (Debezium) из DWH → Kafka
- Развернуть Iceberg + Dremio
- Назначить Data Product Owner

### Месяц 4-6: Второй пилот — Пациентский поток
- Data Products: регистрации, приёмы, расписание
- Настроить DLQ и мониторинг
- Первые дашборды в Superset
- Провести демо для бизнеса (Quick Win)

**KPI**: 2 домена на Data Mesh, 5+ Data Products, время отчёта: часы → минуты

---

## Этап 2: Масштабирование (6-18 мес.)

**Бизнес-цель**: расширить охват, запустить портал

### Месяц 6-9: Критические домены
- Домен AI/ML: результаты анализов → события
- Домен Управление: инвентарь, персонал
- ACL для интеграции через Camel (мост)
- Schema evolution и версионирование

### Месяц 9-12: Портал самообслуживания
- Развернуть BI Portal (React + Superset)
- Self-service SQL через Dremio
- RBAC на уровне Data Products
- Обучение бизнес-пользователей

### Месяц 12-18: Потоковые витрины
- Kafka Streams для real-time агрегаций
- Streaming витрины для ключевых KPI
- Мониторинг качества данных (DataHub)
- Вывод первых legacy-систем (PowerBuilder)

**KPI**: 5 доменов, 20+ Data Products, портал live, 50% аналитиков на self-service

---

## Этап 3: Поддержка и оптимизация (18-36 мес.)

**Бизнес-цель**: полная автономия доменов

### Месяц 18-24: Отказ от legacy
- Полный вывод SQL Server 2008
- Замена Apache Camel на Kafka-интеграции
- Миграция всех отчётов Power BI → Superset
- Data Lineage для всех потоков

### Месяц 24-30: Новые направления
- Фармацевтика (новый домен)
- Медицинское оборудование (новый домен)
- Гео-репликация для новых регионов
- Multi-tenancy для дочерних компаний

### Месяц 30-36: Зрелость
- FinOps: оптимизация облачных затрат
- Автоматическое качество данных (Great Expectations)
- Data Marketplace для внешних партнёров
- Federated Governance на уровне холдинга

**KPI**: 7+ доменов, 50+ Data Products, 0 legacy, 100% self-service, near-real-time
