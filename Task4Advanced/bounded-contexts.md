## Взаимодействие контекстов

| Upstream | Downstream | Тип связи | Описание |
|----------|-----------|-----------|---------|
| Медицина | AI/ML | Events (Kafka) | Результаты исследований для AI-анализа |
| AI/ML | Медицина | Events (Kafka) | Результаты AI-предсказаний для врачей |
| Финтех | Аналитика | Events (Kafka) | Финансовые транзакции для отчётности |
| Медицина | Аналитика | Events (Kafka) | Медицинские данные для дашбордов |
| Управление | Аналитика | Events (Kafka) | Данные инвентаризации и персонала |
| Медицина | Финтех | ACL | Страховые продукты (связь пациент-клиент) |
| Legacy DWH | Все домены | ACL Bridge | Исторические данные через Camel (временно) |
